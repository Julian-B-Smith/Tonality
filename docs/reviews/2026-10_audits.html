How independence was kept

The doctrine says a reviewer is independent only if it comes from a different lineage than the author. Most recent work was Opus 5.5's, so:

Efficiency: clean roomThe spec was isolated (what the engine must promise, no module names). An Opus 5.5 agent that never saw the code designed the system from it, then its 22 smell detectors were run against the real code.
Drift: Sonnet 5.5Every documented claim checked mechanically: imports, counts, commands. It listed the claims that held as well as the ones that didn't.
Security: Sonnet 5.5Briefed to assume the author was overconfident. Capped probes, with growth measured at n, 2n and 4n and then extrapolated.
VerificationI re-ran a sample of every audit's findings before recording them. The tables say which ones.

One leak, disclosed by the clean-room agent itself: the harness showed it the root CLAUDE.md, so it saw the layer names, but no code. Where its layering matches the real one, that agreement counts for less.

The 1.0 plan and the plan map

You asked for a 1.0 "based on what a system like this would promise in its idealized form". The clean-room agent answered that independently. I reconciled its answer against main and wrote down where I depart from it: the bridge is stable, the SDK 2.x port is a MUST, Windows is NICE, and performance numbers get measured before they're promised.

  • Stability tiers. Only "stable" is frozen, which is how 1.0 ships everything without promising everything. The proposed experimental four are rule induction, statistical style, repair and groove apply.
  • Critical path: identity → keys → structural keys → modal transform → plan framework → 1.0.
  • Proposed order: close P0.3 → scrape RE-7 → tiers and locks → plan framework and voicing template → SDK 2.x, determinism matrix and performance → docs and release.

docs/design/1.0-PLAN.md and docs/design/plan-map.html are kept in agreement by tests/test_plan_map.py (Layer-0). It checks that citations resolve, that the graph has no cycle, that the doc and the map agree, that the critical path is real, and that the snapshot titles are current. Each check has a must-fail control, proven on real-file plants. The page's own JavaScript runs the same six checks, green against the real files.
